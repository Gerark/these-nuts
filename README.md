# TheseNuts — Android

Questa versione incapsula la pagina statica dentro un'app Android basata su WebView.
L'HTML originale vive ora in `app/src/main/assets/index.html` e viene caricato
localmente all'avvio dell'app.

## Requisiti
- Android Studio (o Gradle + JDK 17)

## Avvio
1. Apri il progetto con Android Studio.
2. Sincronizza Gradle.
3. Esegui l'app su emulatore o dispositivo.

## Note
- La UI resta identica alla versione web (con Tailwind via CDN).
- Le formule sono placeholder come nella versione originale.
